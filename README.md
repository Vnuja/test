# Seeyou Mart — Seeyou Lanka Co., Ltd.

Static e-commerce website (HTML/CSS/JS, no build step).

- `index.html` — the whole site (products are in the `PRODUCTS` list inside the `<script>`)
- `images/` — logo and product images

## Deploy on Vercel via GitHub
1. Create a new GitHub repository and upload all files in this folder (keep the `images` folder).
2. Go to vercel.com → **Add New → Project** → import the repository.
3. Framework Preset: **Other**. Leave Build Command and Output Directory empty.
4. Click **Deploy**.

## Edit products
Open `index.html`, find `const PRODUCTS = [`, and edit name, price (in won), description or features.
To add a product: put a 640×640 JPG in `images/`, add it to the `IMG` list, then add an entry to `PRODUCTS`.
